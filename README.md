# jamesboehmer/homebrew-tap

Homebrew formulae by James Boehmer.

```sh
brew install jamesboehmer/tap/xbelite2-configurator
```

Or tap it once, then install by name:

```sh
brew tap jamesboehmer/tap
brew install xbelite2-configurator
```

| Formula | Description |
|---|---|
| [xbelite2-configurator](https://github.com/jamesboehmer/xbelite2-configurator) | Remap Xbox Elite Series 2 paddles, buttons and profile colors on macOS and Linux |

Formulae are updated automatically when a new version is released.
